AI skill for Polish law and administration

Prawnik PL provides open-source instructions and tools for AI agents, including Codex. Use it to find and verify the legal basis for an answer, work out deadlines, and draft legal documents. You can ask questions in Polish or English.

Install the skill Explore the examples

Three cases you can test

We ran three fictional scenarios in Polish in Codex. In these initial tests, the skill identified the relevant legal provisions and produced a suitable draft for each case. Below are English translations of the prompts, summaries of the responses, and links to official sources.

Administrative procedure

Appealing a housing benefit refusal

The appeal deadline in the example was 23 November 2026. Codex explained why it shifted from Saturday, flagged that ordinary email was ineffective for filing the appeal, and drafted the appeal.

Polish Code of Administrative Procedure
Show the prompt 
$prawnik-pl It is 19 November 2026. On 3 November the mayor refused my housing benefit application. I picked up the decision in person at the post office on Saturday, 7 November. The decision says I have 14 days from service to appeal to the Local Government Appeals Board (SKO) through the mayor. I suspect the office counted one payment twice. I have a certificate from my employer and a copy of my application.

Give me the last day to appeal, show how you calculated it, and check whether I can file by ordinary email. Prepare a short appeal with placeholders for my details and attachments.

Consumer rights

Getting a refund for a leaking espresso machine

The distance-sale withdrawal deadline in the example was 20 November 2026. Codex compared withdrawal, a statutory complaint to the seller, and a guarantee claim, then drafted a message to the seller.

Polish Consumer Rights Act
Show the prompt 
$prawnik-pl It is 19 November 2026. I bought an espresso machine as a consumer from a Polish online store for PLN 1,249. I received it on 6 November. On the third use, water started leaking from the casing, so I unplugged it. On 16 November I wrote to the store: “The espresso machine is leaking. Please tell me how to report the fault.” The next day the store directed me to the manufacturer’s service department. I have proof of purchase and a video of the leak.

I want my money back. Compare my options, say whether I need to act today, and draft a message to the seller. Explain which requests I can make immediately and which depend on other circumstances.

Residential tenancy

Recovering a deposit after moving out

The deposit was due on 30 October 2026 in the example. Codex calculated four possible balances (PLN 2,000, 1,500, 500, or 0), identified supporting evidence, and drafted a demand for payment.

Polish Tenant Protection Act
Show the prompt 
$prawnik-pl It is 19 November 2026. I rented a flat on a standard lease from 1 October 2024 to 30 September 2026. Monthly rent was PLN 2,500 and the deposit was PLN 3,000. I returned the keys on 30 September. The signed handover report records “minor signs of wear on the walls” and the electricity meter reading. I had no rent arrears.

On 7 November the landlord returned PLN 1,000. In an email, the landlord said PLN 1,500 was deducted for painting and PLN 500 for electricity. No bills were attached. I have photos from the start and end of the tenancy. How much can I claim depending on which deductions the landlord can justify? Check the deposit deadline, identify what evidence I need, and draft a demand for payment.

Coverage and source verification

What does Prawnik PL cover?

Prawnik PL supports research on Polish law and administrative procedure. It covers areas including civil, consumer, tenancy, employment, and family law. In Codex, you can use it to check the grounds for an administrative appeal, calculate a filing deadline, or draft a consumer complaint or demand for payment.

How does the skill check current law?

The instructions require agents to verify the rules that determine the answer against current official sources, such as Poland’s ELI legislation database and CBOSA administrative court database. Live verification requires internet access. The local Python calculator works from supplied inputs to calculate deadlines and interest.

Skill instructions and source verification rules

Install Prawnik PL

In your project folder, run the command below. You need Node.js 22.20 or later and npm. Open the project in Codex, select $prawnik-pl, and paste your question.

Install in Codex

npx skills add denis-solodov/prawnik-pl --skill prawnik-pl --agent codex --copy --yes
Download the v1.0.0 ZIP Full installation guide on GitHub

Install in other agents

Download the v1.0.0 ZIP above. For folder-based installation, extract it and keep the entire prawnik-pl folder with its supporting files.

Claude Code

Put the folder at .claude/skills/prawnik-pl/ in your project. In Claude Code, enter /prawnik-pl. Claude Code docs

Claude Desktop and Claude on the web

Use Upload a skill to upload the ZIP and enable the skill in your account. This requires code execution to be enabled. Claude skill upload guide

Hermes Desktop and Hermes Agent

Copy the folder to ~/.hermes/skills/prawnik-pl/ on the machine running Hermes with the default profile. Start a new session and enter /prawnik-pl. Hermes skills docs

OpenClaw

Run the command below for the active workspace. Check that the skill appears in openclaw skills list. OpenClaw docs

openclaw skills install git:denis-solodov/prawnik-pl@v1.0.0

Cursor

Put the folder at .cursor/skills/prawnik-pl/ in your project. Select the skill from the / menu in Agent chat. Cursor docs

GitHub Copilot

Put the folder at .github/skills/prawnik-pl/ in your project repository and ask Copilot to use Prawnik PL. GitHub Copilot docs

About the research project

We developed Prawnik PL while preparing a research publication and released it as a public beta under the MIT License. The research will assess answer quality across a wider set of cases. Independent review of the results is still pending.

The project was co-authored by Dr. habil. Denis Solodov, associate professor at the University of Warmia and Mazury in Olsztyn (ORCID), and Dr. Ilia Solodov, a lawyer and digital forensics specialist.

Help test the beta

Lawyers, researchers, law students, and anyone using AI agents are welcome to test the beta. We’re particularly interested in deadlines the skill gets wrong, exceptions it misses, and answers that diverge from official sources.

When filing a report, include the skill and model versions, your anonymized question, and the relevant passage from the answer. For legal errors, cite the official source and specify the date for which the rule should be checked.
