# Gdzie się zwrócić w Polsce

Dobór organu wynika z **charakteru sprawy i etapu**, a nie samej nazwy problemu. Ustal właściwość, tryb, termin, kanał wniesienia, ewentualny obowiązek wezwania/ponaglenia lub przedsądowego postępowania.

| Problem | Typowy adresat / ścieżka | Sprawdź |
| --- | --- | --- |
| Przestępstwo, groźby, oszustwo | Policja lub prokuratura | bezpieczeństwo 112, zabezpieczenie dowodów, uprawnienia pokrzywdzonego, właściwość. |
| Wykroczenie i mandat | organ nakładający mandat / właściwy sąd w trybie KPW | przyjęcie mandatu, prawomocność, zamknięty katalog podstaw uchylenia. |
| Spór cywilny (dług, umowa, odszkodowanie) | właściwy sąd rejonowy lub okręgowy, ewentualnie mediacja | właściwość, tryb procesowy/nieprocesowy, opłata. |
| Spór z pracodawcą | sąd pracy; kontrolnie Państwowa Inspekcja Pracy | **21 dni** w określonych odwołaniach od rozwiązania umowy, nie zastępuje ich zawiadomienie PIP. |
| Wadliwy towar/usługa konsumencka | sprzedawca/usługodawca, rzecznik konsumentów, Inspekcja Handlowa, ADR | prawidłowe żądanie, termin, status konsumenta i podmiotu. |
| Decyzja administracyjna | właściwy organ II instancji **za pośrednictwem** I instancji | KPA lub prawo szczególne; pouczenie. |
| Bezczynność/przewlekłość urzędu | ponaglenie / skarga WSA według właściwego trybu | KPA art. 37, p.p.s.a. i szczególne warunki dopuszczalności. |
| Decyzja ostateczna / akt urzędu po wyczerpaniu toku | WSA (a potem NSA, jeśli dopuszczalne) | skarga 30 dni w typowym trybie, wniesienie przez organ. |
| Podatki i VAT | właściwy naczelnik US/KAS, organ odwoławczy, sąd administracyjny | Ordynacja podatkowa, ustawy podatkowe, terminy szczególne. |
| Spór z bankiem/ubezpieczycielem | reklamacja → Rzecznik Finansowy / Arbitraż Bankowy / sąd (zależnie od sprawy) | czy środek polubowny obowiązkowy, transakcja autoryzowana czy nie, organ nadzoru KNF nie rozstrzyga indywidualnego roszczenia. |
| Egzekucja cywilna | komornik sądowy, sąd egzekucyjny, ewentualnie KRZ | właściwy środek: skarga na czynności, powództwo przeciwegzekucyjne, wniosek o ograniczenie egzekucji; terminy różne. |
| KRS i rejestracja spółki | sąd rejestrowy / Portal Rejestrów Sądowych | elektroniczny tryb, opłaty, reprezentacja. |
| Działalność jednoosobowa | CEIDG przez biznes.gov.pl / urząd gminy | status działalności, PKD i szczególne licencje. |
| Nieruchomości, KW | sąd wieczystoksięgowy, starostwo (ewidencja), gmina, nadzór budowlany | wpis do KW ≠ pozwolenie budowlane ≠ dane EGiB. |
| Migracja, pobyt, ochrona | wojewoda, Szef Urzędu do Spraw Cudzoziemców, Straż Graniczna, sąd administracyjny | rodzaj sprawy i szczególny organ/termin, prawo UE i terminy przejściowe. |
| Dane osobowe | UODO | administracyjne skargi zgodnie z RODO, prawa z art. 12–22 RODO, przedtem kontakt z administratorem gdy właściwy. |
| Dyskryminacja, naruszenia praw | RPO, odpowiedni organ, sąd | RPO nie zastępuje środka zaskarżenia ani jego terminu. |
| Pomoc nieodpłatna | punkty nieodpłatnej pomocy prawnej, poradnictwa obywatelskiego / mediacji | [zapisy](https://zapisy-np.ms.gov.pl/) oraz [gov.pl](https://www.gov.pl/web/nieodplatna-pomoc/np); sprawdź uprawnienie, możliwość porady zdalnej i lokalizację. |

## Zasady e-złożenia i doręczeń

- Sprawdź, czy pismo składa się papierowo, pocztą operatora wyznaczonego, przez e-Doręczenia, ePUAP, PRS, KRZ, e-Sąd lub właściwy system sądowy. Od 2025–2026 przepisy i terminy wdrożeń e-Doręczeń zmieniają praktykę; nie zakładaj, że adres na stronie internetowej jest prawnie skutecznym kanałem.
- Zawsze wskaż **właściwy organ**, adres wyłącznie z urzędowego źródła, wymagane podpisy oraz potwierdzenie doręczenia/nadania.
- W pilnej sprawie zaproponuj równoległe zabezpieczenie dowodu dochowania terminu i kontakt z pełnomocnikiem.
